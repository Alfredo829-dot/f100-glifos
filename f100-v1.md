# F100 v1.0 — Diccionario de glifos para edición de fotos

**Nombre:** F100  
**Versión:** 1.0  
**Fecha:** 2026-11-08 (America/Mexico_City)  
**Propósito:** Abreviaturas visuales modulares para prompts de edición de fotos (ropa, posturas, luz, fondo, retoque, calidad). **No son magia, hechizos ni autorizaciones.**

**Límites de contenido:** tasteful; sin desnudez; sin menores; sin «quitar ropa»; sin suplantar personas reales; «atrevido» = fashion-forward refinado, no sexual.

---

## 1. Resumen de cómo funciona

F100 es un **diccionario de atajos tipográficos** para describir ediciones de imagen. Cada símbolo es un token compuesto `forma+subíndice` (p. ej. `●₀`) con un ID ASCII estable (`F01`…`F100`) y un significado operativo concreto.

- **10 familias × 10 tokens = 100 símbolos exactos.**
- Bases (distintas a G100): `● ■ ▲ ◆ ⬢ ⊛ ⊠ ▣ ⊗ ◍`
- Subíndices: `₀₁₂₃₄₅₆₇₈₉` (el `₀` es identidad de slot, **no** prioridad).
- Cada `forma+subíndice` cuenta como **un** símbolo del catálogo.
- Los operadores de gramática (` ; ` `par` `si` `repetir`) **no** son símbolos del catálogo.
- Compatible en gramática con G100, pero **bases distintas** para no colisionar.

### Qué sí hace / qué no hace

| Sí | No |
|----|----|
| Comprimir **descripciones** de edición fotográfica | Prometer magia ni ejecución automática |
| Expandirse a fragmentos de prompt ES/EN | Sustituir el diccionario ante otros modelos |
| Combinarse en cadenas cortas (4–8 glifos) | Autorizar desnudez, menores o suplantar famosos |
| Servir de shorthand humano ↔ app ↔ agente | Cambiar el significado sin este documento |

**Regla práctica:** pega la **cadena de glifos** + el **prompt expandido**, o pega este diccionario, para que Gemini / ChatGPT / Grok Image entiendan.

## 2. Gramática mínima (operadores sintácticos ≠ catálogo)

```
A(args) ; B(args)          → secuencia (A luego B)
par(A, B)                  → ramas independientes en paralelo
si(cond, A, B)             → si cond entonces A, si no B
repetir(n, A)              → repetir A hasta n veces (límite explícito)
```

Argumentos opcionales entre paréntesis, en español claro, p. ej. `■₂(vestido rojo)`.

**Ejemplos válidos:**

1. `●₀ ; ●₈(ropa) ; ■₂(vestido rojo) ; ▲₁ ; ⊠₁ ; ◍₀`
2. `●₀ ; ●₁ ; ■₅ ; ▲₄ ; ⬢₁ ; ⊛₁ ; ⊠₂ ; ◍₂`
3. `●₀ ; ◆₀(negro) ; ▲₂ ; ⬢₈ ; ⊛₀ ; ⊠₀ ; ▣₂ ; ◍₀ ; ◍₆`
4. `par(■₂, ▲₁) ; ⊠₁ ; ▣₉(estudio) ; ⊗₀ ; ◍₀`
5. `●₃ ; si(quiere_cambiar_pose, ⬢₁, ●₃) ; ◍₇`

## 3. Nota breve

Familia 1 fija identidad antes de editar. Familias 2-4 cubren prenda/estilo/material. 5-8 cubren pose/cámara/luz/fondo. 9 es retoque conservador. 10 cierra calidad y empaquetado. Preferir cadenas de 4-8 glifos. Expandir a prosa ES/EN antes de pegar en Gemini/ChatGPT/Grok Image.
