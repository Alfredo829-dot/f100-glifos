# F100 — Glifos para edición de fotos

Diccionario de **100 glifos técnicos** (F01–F100) para armar prompts de edición de fotos: ropa, posturas, luz, fondo, retoque y calidad.

## App

Abre la página de GitHub Pages (este repo) o el archivo `index.html` en el celular.

1. Escribe en español lo que quieres.
2. Toca **Armar glifos**.
3. Copia la cadena y/o el prompt expandido (ES/EN).
4. Pégalo en Gemini / ChatGPT / Grok Image junto con tu foto.

**Nota:** otros modelos no entienden F100 solos. Usa el prompt expandido o pega `f100-v1.md`.

## Archivos

- `index.html` — app mobile-first (sin CDN, todo local)
- `f100-v1.md` — diccionario legible
- `f100-v1.json` — catálogo machine-readable

## Gramática (igual que G100)

`A ; B` · `par(A,B)` · `si(cond,A,B)` · `repetir(n,A)`

Bases F100 (no colisionan con G100): ● ■ ▲ ◆ ⬢ ⊛ ⊠ ▣ ⊗ ◍

## Límites

Tasteful. Sin desnudez, sin menores, sin «quitar ropa», sin suplantar personas reales. «Atrevido» = fashion-forward refinado.
